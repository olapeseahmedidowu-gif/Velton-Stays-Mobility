# Velton Stays & Mobility

Responsive website for a hospitality, property and mobility company in Abuja, Nigeria.

**Live site:** (https://veltonstayandmobility.netlify.app/)

## What I built
- Six-page responsive website
- Enquiry form with Book a stay / Book a ride, sending to email or WhatsApp
- Shortlet search section and floating WhatsApp button
- White, gold and green brand design from a Figma mock-up

## Tools
HTML, CSS, JavaScript. Designed in Figma. Hosted on Netlify.
